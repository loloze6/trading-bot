## Stop 14

**Correction (<date>).** Step 5, the manifest and the core block. 1. The "engine version" in the manifest is the git commit id of the checkout (`git_sha`). When a tracked file is modified, it carries the suffix `-dirty`, and untracked files are ignored (`TB/reporting/run_artifact.py:143-155`). The core block's Sharpe ratio and drawdown are measured on closed trades, not bar by bar (`run_artifact.py:627-628`, from the tracker at `TB/performance/metrics.py:1421-1422`). The Sharpe ratio sums trade returns by exit date, fills days with no exit with zero only between the first and the last exit date, and annualises with the square root of 365 (`metrics.py:1464-1499`). The drawdown is taken on a curve compounded trade by trade from `portfolio_impact_pct`, sorted by exit time (`:1444-1462`). The bar-by-bar Sharpe ratio and drawdown are in a separate block, `bar_equity` (`run_artifact.py:807-815`). The data dictionary records the trade-exit basis as A9 (`SR/docs/DATA_DICTIONARY.md:673-675`).
