Idea: In any market, after the first up day that ends a run of down days, the price keeps falling on the second and third days after that up day, and this later fall is larger the more down days the run held.
Consequence: Unhurried trapped holders sell in pieces, so the fade is spread over days and does not end on the first day after the break.
