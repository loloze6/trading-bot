Idea: In a falling market, the first up day after a run of consecutive down days is followed by a fall in the coin's close over the next day, and the longer the run of down days that the up day ends, the larger that next-day fall.
Consequence: Holders trapped by a run of down days in a downtrend sell into the first up day, and a longer run leaves more trapped supply, so a deeper next-day fall follows.
