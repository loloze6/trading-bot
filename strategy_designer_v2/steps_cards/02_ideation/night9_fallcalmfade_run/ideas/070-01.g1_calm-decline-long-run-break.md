Idea: In a falling, calm market, an up day that ends a run of down days is followed by a fall over the next day. The fall is larger the more down days that run held beyond the first, so the up day after a single down day is followed by almost no fall.
Consequence: A trader fading relief days in a quiet decline should bet on the breaks of long down runs and give little weight to the break of a single down day, which carries almost nothing.
Why:
- F2: The tested book weighted 1-day runs, which carry almost nothing. In the falling calm profile, up days after a 1-day run were followed by -0.23 % (t -0.80, 226 cases). After a 2-day run the move was -0.91 % (t -2.05, 125 cases), after a 4-day run -1.25 % (22 cases), and after runs of 5 days or more -2.12 % (t -3.09, 36 cases). Yet 634 of the backtest's 870 cases were 1-to-2-day runs, so its main t was only 0.98.
- F1: Across all coins and profiles, an up day that ends a run of down days is followed by a next-day unusual fall that depends on the run's length. After a 1-day run the fall is only -0.20 % (t -0.85, 1236 cases, 463 days). After a 2-day run it is -1.03 % (t -3.07, 551 cases, 263 days), and after runs of 5 days or more it is -2.37 % (t -3.53, 76 cases, 56 days); these t take the cases of one day together.
- F5: This move is about 5 to 8 times the 0.19 % cost of a trade. The run-2+ cases move about -1.0 % per case unusual, against +0.20 % for the tested idea's case mix. The tested book earned +1.3 % a year, and almost all of its gain came from two windows, w7 (+0.10 %/day) and w14 (+0.07 %/day); the other windows were near 0 or negative.
