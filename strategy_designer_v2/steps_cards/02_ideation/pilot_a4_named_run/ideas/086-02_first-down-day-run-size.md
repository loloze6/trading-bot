Idea: In a rising, agitated market, when a coin closes down after a streak of consecutive up days, it keeps falling over the next 3 days, and the fall is larger the bigger the streak's total gain, measured in units of the coin's daily swing over the last 30 days.
Consequence: The first down day after an up run starts a staged decline, and the decline grows with the size of the run against the coin's usual swing.
