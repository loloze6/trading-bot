Idea: In a rising, agitated market, on the first up day after a run of consecutive down days, the coin rises over the next 5 days, and the more down days the run had, the larger that rise.
Consequence: The first up day after a down run marks the end of forced long liquidation, and waiting buyers arrive over the following days, more of them the longer the run lasted.
