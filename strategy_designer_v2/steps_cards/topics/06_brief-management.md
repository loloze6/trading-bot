# Topic 06: Brief management

Status: open (larger topic)  
Where: research: briefs  
Opened: 2026-11-17 (operator)

## Question
Once a brief's run is over, where does its answer live, and how is a brief archived or reopened?

## Seen
- The operator's grouping: **result loop back** (a file next to the brief, not inside it, saying what its run found:
  its ideas' results, its blocked ideas, where the lines went), **brief archiving**, **brief reopening**.
- Seen: the answer to "which of the theory's ideas are real and pay" was written by hand in `runs/NIGHT_RUN.md`; no file
  holds it.

## Why it matters
Without it, a brief's answer is scattered over a run's files and has to be rebuilt by hand.

## Options
| Option | Gain | Risk |
|---|---|---|
| A result file per brief, written by code from the run's files | the answer in one place | one more file to keep right |

Recommended: the result file first, when opened.
