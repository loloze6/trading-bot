Idea: The larger a coin's last 1-day return relative to its 20-day volatility of daily returns, the higher its return over the next 7 days.
Consequence: A strong up day, large for the coin's recent volatility, is a reason to hold or add to the coin for the following week.
Why:
- F4: The last day's return scaled by 20-day volatility predicts a higher excess 7-day return (slope 0.0074, t 2.33 on 671 cases; t 2.44 with the move clipped at ±3), with the same sign in both coins (BTC t 1.65, ETH t 1.70), mostly from up days (t 1.77 vs 0.27 on down days); this is borderline given the many angles looked at.
