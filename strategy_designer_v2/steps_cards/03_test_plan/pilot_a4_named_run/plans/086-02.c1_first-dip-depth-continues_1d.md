Fidelity:
- Situation: a coin closes down after a streak of consecutive up days, in a rising agitated market -> kept: the profile is added by code; a regime fires only on the down close that breaks an up run of 2 or more days.
- Comparison: the depth of that down day in units of the coin's 30-day daily swing -> kept: the day's return over the 30-day std of daily returns grades the short.
- Outcome: the coin keeps falling over the next 5 days, more after deeper dips -> kept: the short is held 5 bars.
- Verdict transfer: yes: the test bets on exactly the stated dip, sized by the stated depth, over the stated 5 days.
Forecast: The regime detector reads `PriorDownRunOnUpCloseComponent` (side "up", count). On a down close, this counts the up days the close breaks. The regime is active only when that count is 2 or more, which is the first dip after an up streak. Every other bar is flat. Inside the regime, the forecast is `VolatilityScaledReturnComponent` (period 1, vol_period 30): the day's return in units of the 30-day std of daily returns. It is standardised over its past 60 values and clipped at 0. On a dip day it is negative (short), and its size grows with how deep the fall is against the coin's usual swing. It is never positive. The forecast is nonzero only on the dip bar, and the holding period keeps the short for 5 bars.

Side: short only (the brief): each component's forecast capped at 0 by step 3's code
Profile: rising agitated (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 5 bars
- Main measure: The mean unusual move over 5 bars in the short direction. A case is a bar where the forecast makes a short bet, read once per 5-bar grid cell. The unusual move is minus the coin's 5-bar forward return less its normal 5-bar drift over all windows. Its t groups the cases by day.
- Supporting check: The mean short-direction unusual move of cases with |forecast| above the cases' median, minus that of cases below it, is above 0.
- Confirm: The main measure is above 0 with t >= 2, and the supporting check passes.
- Reject: The main measure is below 0 with t <= -2, meaning prices rise more than their usual drift after the dip.
- Inconclusive: Any t between -2 and 2, or a confirming main measure with a failed check. The minimum is 30 days carrying cases; with fewer, the test is inconclusive.
