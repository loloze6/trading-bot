Fidelity:
- Situation: a coin's one-day rise, in a rising agitated market -> adapted: the one-day return in 30-day standard deviations, clipped at 0 and graded; the profile is added by code.
- Comparison: the rise measured against the standard deviation of daily returns over the last 30 days -> kept
- Outcome: the next day's rise, larger after larger scaled rises -> kept
- Verdict transfer: yes: the graded long position is the scaled rise itself, held one day, so its next-day gain tests the idea directly.
Forecast: The day's return divided by the standard deviation of the last 30 daily returns (`VolatilityScaledReturnComponent`, period 1, vol_period 30). It is put on the forecast scale by `standardise` over its past 60 values (min 20), then clipped at 0. The forecast is positive on up days and grows linearly with the size of the scaled rise, up to the cap of 20. It is 0 on down and flat days. It is never short. Outside the rising agitated profile, code keeps the book flat.

Profile: rising agitated (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 1 bar
- Main measure: Use bars with forecast > 0. Take the next-day return close[t+1]/close[t]-1 minus the coin's mean daily return over all its windows. Measure the mean of this excess return weighted by the forecast. Its t is computed with the cases of one day summed together.
- Supporting check: On those bars, the least-squares slope of the next-day excess return on the forecast is positive.
- Confirm: The forecast-weighted mean excess return is positive with t >= 2, and the slope is above 0.
- Reject: The forecast-weighted mean excess return is negative with t <= -2.
- Inconclusive: Any t between -2 and 2 is inconclusive. So is a positive t >= 2 with a slope at or below 0. Fewer than 100 cases, or cases on fewer than 100 distinct days, is also inconclusive.
