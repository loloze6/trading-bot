Fidelity:
- Situation: in a choppy calm market, a positive 14-day return against the coin's 30-day daily swing -> kept: the 14-day return over the 30-day std of daily returns, long side only; the code adds the profile.
- Comparison: the larger the swing-scaled rise, the larger the further rise -> kept: the long position grows with the swing-scaled rise.
- Outcome: the coin keeps rising over the next 7 days -> kept: 7-bar forward return, judged against the coin's normal drift.
- Verdict transfer: yes: the same quantity, side, profile and horizon are tested, so a confirm or a reject carries straight to the idea.
Forecast: The forecast uses VolatilityScaledReturnComponent with period 14 and vol_period 30. Its raw value is the 14-day return divided by (the 30-day std of daily returns x sqrt(14)), signed like the move. Standardise puts it on its own past scale (window 60, min_periods 20), and a clip at 0 keeps only rises. The forecast is 0 when the 14-day swing-scaled move is zero or negative. It is positive and grows in proportion as the swing-scaled rise grows, up to the cap of 20. There is no dead zone, because the idea says not to wait for an extreme. The code keeps the book flat outside the choppy calm profile.

Profile: choppy calm (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 7 bars
- Main measure: Use in-profile grid bars: non-overlapping 7-bar grid per window, bars whose regime is the profile's active regime. The measure is the slope of the coin's 7-bar forward return minus its normal drift (its mean 7-bar return over all windows) on the bar's forecast. Its t uses deviations summed per day.
- Supporting check: The mean unusual move (7-bar forward return minus drift) over grid cases with forecast > 0 is above 0.
- Confirm: The slope is positive with t >= 2 and the supporting check's mean is above 0.
- Reject: The slope is negative with t <= -2.
- Inconclusive: Any slope with t between -2 and 2 is inconclusive. So is a positive slope with t >= 2 whose supporting mean is at or below 0. The test needs at least 100 grid cases with forecast > 0, falling on at least 50 distinct days; with fewer it is inconclusive.
