Forecast: The forecast starts from the close's distance from its 20-day simple average, as a share of the average. It divides that by the standard deviation of the last 20 daily returns, so the stretch is counted in usual daily moves. This is standardised against its own past 60 values, then clipped at a maximum of 0. It is negative when the close is below the average, and its size grows with the stretch, up to the cap of -20. It is zero at or above the average, so the book never goes long. Step 3's code adds the choppy agitated profile, and the book is flat outside it.

- Main measure: The cases are the bars of each window's non-overlapping 5-bar grid with a forecast below 0. On each case, take the coin's 5-day return minus the coin's mean 5-day return over all windows, in the short direction (its negative). Average these weighted by abs(forecast). The t clusters cases of the same day together.
- Supporting check: Size order. Split the cases at the median abs(forecast). The mean short-direction excess return of the larger half minus that of the smaller half must be above 0.
- Confirm: The weighted mean short-direction excess return is above 0 with t ≥ 2. The supporting check is also above 0.
- Reject: The weighted mean short-direction excess return is below 0 with t ≤ -2. That means stretched-below closes are followed by a return toward the average.
- Inconclusive: Any t between -2 and 2 is inconclusive. So is a main measure with t ≥ 2 whose size check fails. So is a result from fewer than 30 cases, or cases falling on fewer than 30 distinct days.
