Criterion:
- Horizon: 10 bars
- Main measure: The slope of the coin's 10-bar forward return, minus that coin's mean 10-bar return over all windows, on the bar's forecast. - It is read on the non-overlapping 10-bar grid of each window, on bars with a nonzero forecast. - Its t takes cases on the same day together.
- Supporting check: Both sides must show the carry. - On long cases (forecast > 0), the drift-adjusted 10-bar return is above 0. - On short cases (forecast < 0), that return, sign-flipped, is above 0.
- Confirm: The slope is positive with t ≥ 2 and the supporting check passes on both sides.
- Reject: The slope is negative with t ≤ -2, which means stretches revert toward the average.
- Inconclusive: Any slope with |t| < 2 is inconclusive. So is a positive slope with t ≥ 2 whose carry shows on one side only. The test needs at least 200 grid cases with a nonzero forecast, including at least 50 on each side; with fewer it is inconclusive.
