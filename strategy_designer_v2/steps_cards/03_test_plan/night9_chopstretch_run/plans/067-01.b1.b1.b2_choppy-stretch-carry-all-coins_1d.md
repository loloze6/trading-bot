- Outcome: the price keeps moving the stretch's way over the next 5 days, more for a larger stretch -> kept

Forecast: One component, `MovingAverageDistanceComponent` (SMA 20, `base` "usual_moves", `vol_period` 20). It gives (close − SMA20) / SMA20 divided by the 20-day standard deviation of daily returns. It is standardised over its past 60 values (min 20), so its typical size is about 10, capped at ±20. The forecast is positive (long) when the close is above the average and negative (short) when below. It is 0 at the average and grows linearly with the stretch in usual moves. The detector is ungated. Step 3's code adds the choppy profile, so the book is flat outside it.

Criterion:
- Horizon: 5 bars
- Main measure: On non-overlapping 5-bar grid bars with a nonzero forecast, take the mean of (forecast / 10) x (the coin's 5-bar forward return minus the coin's mean 5-bar return over all windows). Its t treats cases on the same day as one.
- Supporting check: The same mean, computed separately on long-forecast cases and on short-forecast cases, is above 0 on each side.
- Confirm: The main measure is above 0 with t ≥ 2, and the supporting check passes on both sides.
- Reject: The main measure is below 0 with t ≤ −2, meaning stretches revert.
- Inconclusive: Any t between −2 and 2 is inconclusive. A positive t ≥ 2 that fails the two-side check is also inconclusive. A test needs at least 200 cases, with at least 50 on each side, falling on at least 100 distinct days; fewer is inconclusive.
