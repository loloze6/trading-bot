Fidelity:
- Situation: in a falling, agitated market, a one-day rise that stays within the coin's usual daily swing -> kept: the profile is added by code, and a regime holds the book only when 0 < rise/30-day std <= 1.
- Comparison: the rise measured against the 30-day daily swing -> kept: the one-day return divided by the 30-day std of daily returns.
- Outcome: a larger fall over the next day, growing with the rise -> kept: a short graded by the scaled rise, held 1 bar.
- Verdict transfer: yes: the test measures this rise, inside this situation, over this horizon.
Forecast: The forecast uses VolatilityScaledReturnComponent with period 1 and vol_period 30. It is the day's return in units of the 30-day daily std. A regime rule selects mean_reversion only when that value is above 0 and at or below 1, inside the falling agitated profile, which code adds. On every other bar the regime is unknown and the book is flat. Inside the regime the value is standardised over 60 bars and negated. The forecast is therefore always short, near 0 for a tiny rise, and larger the closer the rise comes to one usual swing (about -12 at one swing).

Criterion:
- Horizon: 1 bar
- Main measure: The bars used are those with a nonzero position. On each, take the position held after the bar's trade x (close[t+1]/close[t] - 1), minus the position x the coin's mean daily return over all windows. This is the gain beyond holding, before costs. Its mean is tested with a t, pooling the cases of one day together.
- Supporting check: On those bars, regress the signal-direction next-day return (the short's gain, minus the drift) on |forecast|. The check passes if the slope is above 0.
- Confirm: The mean excess gain is above 0 with t >= 2, and the slope is above 0.
- Reject: The mean excess gain is below 0 with t <= -2.
- Inconclusive: Any t between -2 and 2 is inconclusive. A positive mean with t >= 2 but a slope at or below 0 is also inconclusive. Fewer than 100 cases on the 1-bar grid is inconclusive whatever the t.
