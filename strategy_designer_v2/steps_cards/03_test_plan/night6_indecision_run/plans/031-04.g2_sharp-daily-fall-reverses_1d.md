Fidelity:
- Situation: a coin's one-day fall, larger the bigger it is -> kept: the one-bar fall in 20-day volatility units, zero on up days.
- Comparison: the fall against the coin's 20-day daily volatility -> kept: the return divided by the standard deviation of the last 20 daily returns.
- Outcome: a larger rise over the next day -> kept: the next 1-bar return, long, judged against the size of the fall.
- Verdict transfer: yes: the forecast is the idea's own scaled fall, held one day, so a slope of next-day return on it tests the idea directly.
Forecast: The forecast uses one indicator, `VolatilityScaledReturnComponent` (period 1, vol_period 20). It is today's return divided by the standard deviation of the last 20 daily returns. The value is negated, so a fall reads positive, and then standardised against its own past 60 values. It is clipped at 0, so the strategy is long only. The forecast is 0 on every up day or flat day. On a down day it is positive, and its size grows in proportion to how many usual daily moves the fall spans, up to the cap of 20. It is never negative.

Criterion:
- Horizon: 1 bar
- Main measure: Run a least-squares slope of the coin's next-day return, minus that coin's mean daily return over all windows, on the forecast. Use every bar with forecast > 0, pooled over coins and windows. Report the slope's t, with the bars of one day taken together.
- Supporting check: The book's timing gain is above 0. This is its mean daily return minus the gain from the market's own rise, before costs.
- Confirm: The slope's t is 2 or more and the timing gain is above 0.
- Reject: The slope's t is -2 or less.
- Inconclusive: Any t between -2 and 2 is inconclusive. A t of 2 or more with a timing gain at or below 0 is also inconclusive. Fewer than 200 bars with forecast > 0, or fewer than 100 distinct days among them, is too few cases to judge either way.
