Fidelity:
- Situation: coin's 60-day return positive, with a 5-day rise -> kept: the 60-day return above 0 is a regime rule, and the forecast grows with the 5-day rise.
- Comparison: a larger 5-day rise against a smaller one, whatever the day's range -> kept: the forecast is graded by the 5-day rise and has no range term.
- Outcome: rises more over the next 3 days -> kept: horizon 3 bars, long side.
- Verdict transfer: yes: the config holds long only inside 60-day uptrends, sized by the 5-day rise, so a 3-day return that grows with that size confirms the idea and one that falls with it rejects it.
Forecast: The regime detector computes the 60-day percent return (PriceEvolutionComponent, period 60). When it is above 0 the bar is "trending"; on every other bar the book is flat. Inside trending, the forecast is the 5-day percent return (PriceEvolutionComponent, period 5), standardised against its own past 60 values (target 10, cap 20). It is then clipped at 0, so it stays long only. It is 0 when the 5-day return is flat or negative. It grows linearly with the size of the 5-day rise, from about 10 at a usual-size rise up to 20 at twice the usual size or more. It is never negative.

Criterion:
- Horizon: 3 bars
- Main measure: Use the non-overlapping 3-bar grid of each window and keep the bars with regime "trending". On those bars, regress the coin's 3-bar forward return minus its normal 3-bar drift (its mean 3-bar return over all windows) on the bar's forecast. The measure is the t of that slope, taken across all coins and windows.
- Supporting check: On the same grid bars, the forecast-weighted mean of the excess 3-bar return is above 0.
- Confirm: The slope's t is 2 or more and the forecast-weighted mean excess return is above 0.
- Reject: The slope's t is -2 or less.
- Inconclusive: A t between -2 and 2, or a t of 2 or more with a forecast-weighted mean excess return at or below 0. The test needs at least 100 grid bars in trending with forecast above 0; with fewer, the result is inconclusive.
