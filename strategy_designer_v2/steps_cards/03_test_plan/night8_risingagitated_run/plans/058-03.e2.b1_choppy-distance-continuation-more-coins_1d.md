It is 0 only at the average. Its size grows linearly with the distance: a usual distance gives about 10, which is 100 percent of the book. It follows the distance rather than fading it, and it shorts when the close is below the average. No regime gate is written here, because the choppy profile is added by code and the book is flat outside it.
