Fidelity:
- Situation: in a choppy, agitated market, a coin's 30-day fall -> kept: the 30-day return is clipped to falls only; the code adds the profile.
- Comparison: the fall measured against the coin's usual 30-day move -> kept: the 30-day return is divided by the mean absolute 30-day return over the past 365 days.
- Outcome: the deeper the fall, the more the coin keeps falling over the next 5 days -> kept: a graded short, held 5 bars.
- Verdict transfer: yes: the forecast is the idea's own measure, and the test reads what follows it over the idea's 5 days.
Forecast: One component, `MeanAbsScaledReturnComponent` with period 30, window 365 and base "mean_abs_return". It gives the coin's 30-day return in multiples of its usual 30-day move over the past year. It is standardised against its own past 365 values (min_periods 91), then clipped at 0 from above. So the forecast is 0 when the last 30 days did not fall. It is negative (short) when they fell, and its size grows in proportion to the depth of the fall in usual moves, up to the cap of -20. It is never positive. The code keeps it flat outside the choppy agitated profile.

Profile: choppy agitated (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 5 bars
- Main measure: Use the non-overlapping 5-bar grid of each window, on grid bars with forecast < 0. Regress the coin's 5-day forward return, minus the coin's mean 5-day return over all windows (holding), on the forecast. The measure is the slope and its t, with the cases pooled across coins and windows.
- Supporting check: On the same bars, the mean of that excess 5-day return is below 0, so the short side gains against holding.
- Confirm: The slope is positive with t >= 2 (a deeper negative forecast is followed by a lower excess return), and the supporting check passes.
- Reject: The slope is negative with t <= -2 (deeper falls are followed by more rebound than shallow ones).
- Inconclusive: A slope t between -2 and 2, or a confirming slope whose check fails. Fewer than 30 grid bars with forecast < 0 is also inconclusive, whatever the t.
