Fidelity:
- Situation: a falling, calm market, and the coin's move over its last 5 days -> kept: the code adds the profile, and the 5-day return is measured on every bar inside it.
- Comparison: the further it fell (or rose) over 5 days, the more it falls (or rises) next -> kept: the position grows with the size of the 5-day return.
- Outcome: the next 5 days continue the last 5 days' direction -> kept: the position follows the past 5-day move and is held 5 daily bars.
- Verdict transfer: yes: the forecast is the idea's own 5-day continuation, graded by its size, inside its own profile.
Forecast: The forecast is the coin's 5-day percent return (`PriceEvolutionComponent`, period 5), standardised against its own last 60 values (min_periods 20). It is positive after a 5-day rise and negative after a 5-day fall, larger the bigger the move, and 0 only for a flat week. The code keeps the book flat outside the falling calm profile.
Config: 058-03.g1_calm-downtrend-weekly-continuation_1d_config.json
Profile: falling calm (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 5 bars
- Main measure: The cases are the bars on each window's non-overlapping 5-bar grid where the forecast is not 0. For each case, take the forecast / 10 times the coin's next 5-bar return minus the coin's mean 5-bar return over all windows (its drift). Measure the mean of these products, with its t, taking the cases of one day together.
- Supporting check: none
- Confirm: The mean signed excess return is above 0 with t of 2 or more, over at least 50 distinct days.
- Reject: The mean is below 0 with t of -2 or less, over at least 50 distinct days.
- Inconclusive: Any t between -2 and 2 is inconclusive, and so is any result with fewer than 50 distinct days of cases.
