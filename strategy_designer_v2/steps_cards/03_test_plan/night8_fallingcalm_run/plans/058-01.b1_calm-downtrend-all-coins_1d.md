- Situation: in a falling, calm market, how far the coin fell over its last 30 days -> kept: the falling-calm profile is added by code, and inside it the 30-day fall is measured as stated.
- Comparison: the deeper the 30-day fall, the more falling follows -> adapted: graded, so the short position grows with the depth of the fall.
- Outcome: the coin keeps falling over the next 5 days -> kept: short, held 5 daily bars.
- Verdict transfer: yes: the forecast is the idea's own fall depth, sized short inside the idea's profile, and is judged on the next 5 days.
Forecast: One indicator, the coin's 30-day percent return (PriceEvolutionComponent, period 30). It is put on the forecast scale by `standardise` over its last 60 values (min 20), then clipped at a maximum of 0 and negated in sign by construction. The forecast is negative (short) when the coin is below its close of 30 bars ago, and grows short as that fall deepens, up to the cap of -20. It is 0 when the 30-day return is zero or positive. The code adds the falling-calm profile, so the book is flat outside it. Each bet is held 5 bars.

Profile: falling calm (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 5 bars
- Main measure: On each window's non-overlapping 5-bar grid, take the bars with forecast < 0. For each, the excess return is close[t+5]/close[t] - 1 minus the coin's mean 5-bar return over all windows. Regress that excess return on the short size (-forecast). The t of the slope is computed with the cases of one day summed together.
- Supporting check: The mean excess return over those cases is below 0, so short cases end lower than the coin's normal drift.
- Confirm: The slope is negative with t ≤ -2 (deeper falls are followed by larger excess falls), and the supporting check passes.
- Reject: The slope is positive with t ≥ +2 (deeper falls are followed by relative rises).
- Inconclusive: A slope t between -2 and +2, or a confirming slope whose supporting check fails. The test needs at least 100 grid cases with forecast < 0, falling on at least 50 distinct days; with fewer, the result is inconclusive.
