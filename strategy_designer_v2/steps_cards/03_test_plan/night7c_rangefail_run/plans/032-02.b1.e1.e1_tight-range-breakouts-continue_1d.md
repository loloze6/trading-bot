- Comparison: how narrow the prior 60-day range of closes is against the coin's typical daily move -> adapted: graded as 1/(1 + range in usual 60-day mean absolute daily moves), so a narrower range gives a larger position.

Forecast: The forecast is zero except on bars whose close is above the highest of the prior 60 closes (DistanceFromHighComponent, period 60, close, prior bars only, above 0). On those bars it is long. Its size comes from ClosingRangeInUsualMovesComponent (period 60, window 60, form "compression"). That component computes 1/(1+W), where W is the prior 60-day closing range divided by the mean absolute daily return of the last 60 days. The value is standardised against its own last 61 values: about +10 for a usual range, up to +20 for a much tighter one, and smaller for a wider one. It is clipped at 0, so it is never short.
