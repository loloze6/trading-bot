- Situation: in a falling, agitated market, a five-day rise whose last day is an up day -> kept: the profile is added by code, "last day up" is a regime rule, and the rise is clipped at zero.
- Comparison: the rise against the standard deviation of daily returns over the past 30 days -> kept: the 5-day return divided by the 30-day return std (a constant sqrt(5) that standardise cancels).
- Outcome: the larger that ratio, the larger the fall over the next day -> kept: a short held 1 bar, sized by the ratio.

Forecast: A regime rule keeps the book flat unless the current day closed up: the 1-day return (`PriceEvolutionComponent`, period 1, sf 1) must be above 0. Bars that pass go to `mean_reversion`. All other bars are `unknown`, which is flat. The falling-agitated profile vetoes are added by code. Inside the regime, `VolatilityScaledReturnComponent` (period 5, vol_period 30) gives the 5-day return in units of the 30-day daily-return std. It is standardised over 60 bars with 20 minimum periods, clipped at 0 so only rises count, then negated. The forecast is therefore 0 when the 5-day window did not rise. Otherwise it is negative (short), and it grows steadily in size with the rally against the coin's usual swing, capped at -20. It is never positive.
