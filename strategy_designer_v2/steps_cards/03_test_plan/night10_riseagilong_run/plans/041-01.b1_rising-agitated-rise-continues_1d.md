Fidelity:
- Situation: a coin's one-day rise, measured against the standard deviation of its daily returns over the last 30 days -> kept
- Comparison: larger scaled rises against smaller ones ("the larger ... the larger") -> kept
- Outcome: the coin rises over the next day, more after larger scaled rises -> kept
- Verdict transfer: yes: the forecast is the scaled one-day rise itself, held for one day inside the rising agitated profile, so the test confirms or rejects exactly this relation.
Forecast: The forecast uses one component, `VolatilityScaledReturnComponent` with `period` 1 and `vol_period` 30. It is today's return divided by the standard deviation (ddof 1) of the last 30 daily returns. The component is standardised against its own past 60 values (min_periods 20), then clipped at 0, so the book is long only on up days. The forecast is 0 on down and flat days. On up days it is positive, and it grows linearly with the rise in usual daily moves, capped at 20. The market-profile code keeps the book flat outside rising agitated.

Criterion:
- Horizon: 1 bar
- Main measure: The sample is the bars with forecast > 0, every bar of each window (1-bar steps never overlap), all coins pooled. For each bar, take the coin's next-day return close[t+1]/close[t] - 1 minus that coin's mean daily return over all its windows (holding the coin). Regress this excess return on the bar's forecast. The measure is the t of the slope, counting the cases of one day together (their deviations summed per day).
- Supporting check: The mean next-day excess return over all bars with forecast > 0 must be positive.
- Confirm: The slope's t is 2 or more, and the supporting check passes.
- Reject: The slope's t is -2 or less: larger scaled rises are followed by smaller, or more negative, next-day excess returns.
- Inconclusive: Any slope t between -2 and 2 is inconclusive. So is a t of 2 or more with a mean excess return of 0 or below. So is any result with fewer than 100 bars with forecast > 0.
