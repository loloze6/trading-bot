Fidelity:
- Situation: a coin's one-day fall, measured against its own past-60-day daily volatility -> kept: the 1-bar return over the std of the last 60 daily returns, positive only on down days.
- Comparison: the rise above the coin's normal drift -> kept: next-day return minus the coin's mean daily return over all windows.
- Outcome: the price rises over the next 1 day, more the larger the scaled fall -> kept: the long size grows with the scaled fall, and the book holds it 1 bar.
- Verdict transfer: yes: the forecast is the idea's own graded scaled fall, so a rise above drift that grows with it confirms the idea, and a fall below drift rejects it.
Forecast: The forecast uses one indicator: VolatilityScaledReturnComponent with period 1 and vol_period 60. It is the day's return divided by the standard deviation of the last 60 daily returns. It is standardised over its past 61 values, then negated, then clipped at 0. The forecast is positive only on down days and grows linearly with the depth of the fall in usual daily moves, about +10 for an average-sized fall and capped at +20. It is 0 on up days and flat days, and never negative, so the idea never takes a short.

Criterion:
- Horizon: 1 bar
- Main measure: Over all bars, the mean of (forecast / 10) x (next-day return minus the coin's mean daily return over all windows). Its t counts the cases of one day together, summed per day.
- Supporting check: On bars with forecast > 0, the mean excess next-day return of the top third of forecasts must be above that of the bottom third.
- Confirm: The main measure has t ≥ 2.0 and the top third's mean excess return is above the bottom third's.
- Reject: The main measure has t ≤ -2.0.
- Inconclusive: Any t between -2.0 and 2.0, and t ≥ 2.0 when the top third is not above the bottom third. The test needs at least 300 distinct days with forecast > 0 across coins and windows; with fewer, the result is inconclusive.
