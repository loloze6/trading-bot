Fidelity:
- Situation: a falling, calm market with the 14-day return below zero, in units of the 30-day daily swing -> kept: the profile is added by code, and the scaled 14-day return is clipped at 0 so there is no position when it is not negative.
- Comparison: how far below zero the decline sits, against the coin's own 30-day swing -> kept: a 14-bar return divided by the 30-bar daily-return std, graded by depth.
- Outcome: a larger fall over the next 5 days -> kept: a short held for 5 bars, sized by depth.
- Verdict transfer: yes: the test measures the same scaled decline, in the same profile, over the same 5-day horizon and on the same side.
Forecast: The forecast is built from VolatilityScaledReturnComponent with period 14 and vol_period 30. Its raw value is the 14-day return divided by (the 30-day daily-return std x sqrt 14). It is standardised over its 60 past values (min_periods 20) and then clipped at a maximum of 0. When the 14-day return is at or above zero, the forecast is 0. Below zero, it is negative (short) and grows in size linearly with the depth of the decline in usual moves, up to the cap of -20. Code adds the falling calm profile, so the book is flat outside it.

Profile: falling calm (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 5 bars
- Main measure: The sample is the non-overlapping 5-bar grid of each window, on bars where the forecast is below 0. On these bars, take the least-squares slope of the coin's 5-day forward return, minus that coin's mean 5-day return over all windows, on the bar's forecast. Errors are clustered by day. This is before costs.
- Supporting check: On those same bars, the mean 5-day excess return (as above) is below 0.
- Confirm: The slope is positive with t ≥ 2: a deeper negative forecast is followed by a larger fall beyond the drift. The supporting mean must also be below 0.
- Reject: The slope is negative with t ≤ -2: deeper declines are followed by smaller falls or by rebounds.
- Inconclusive: A slope with |t| < 2, or a confirming slope with a mean excess return ≥ 0. At least 30 grid cases are needed, on at least 20 distinct days; with fewer, the result is inconclusive.
