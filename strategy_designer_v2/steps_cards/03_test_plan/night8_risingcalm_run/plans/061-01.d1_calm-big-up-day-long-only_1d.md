- Situation: a coin's one-day rise in a calm market -> kept: the calm profile is added by code, and the forecast is zero on down days.
- Comparison: the rise against the standard deviation of daily returns over the past 30 days -> kept: the day's return divided by the 30-day standard deviation, which includes today.
- Outcome: a larger rise over the next 5 days, the larger the day, long only -> kept: the position is held for 5 bars and grows with the day's size in swing units.
- Verdict transfer: yes: the test measures the idea's own graded relation, inside its own profile, on the long side only.
Forecast: The forecast uses VolatilityScaledReturnComponent with period 1 and vol_period 30. Its raw value is today's return divided by the standard deviation of the last 30 daily returns. This value is standardised over the 60 values before today, then clipped at 0. The forecast is therefore positive on up days and grows in proportion to the day's size in swing units, up to a cap of 20. It is exactly 0 on down days and on flat days, and it is never short. The calm profile, added by code, keeps the book flat in agitated markets.
