- Situation: in a calm market, a coin's 14-day return below zero, scaled by its 30-day daily swing -> adapted: the calm market is the brief's profile, added by code; inside it, the 14-day return over the 30-day daily return std is graded and is zero when that return is not below zero.
- Comparison: the depth of the decline against the coin's own usual daily swing -> kept
- Outcome: a larger fall over the next 5 days, the deeper the decline -> kept
- Verdict transfer: yes: the forecast is the idea's swing-scaled decline, short only, inside calm markets, and it is judged on the fall over the 5 days that follow.
Forecast: One component, `VolatilityScaledReturnComponent` with `period` 14 and `vol_period` 30. Its raw value is the 14-day return divided by the 30-day standard deviation of daily returns times sqrt(14). The sqrt(14) is a constant and cancels under `standardise`. The value is standardised over its last 60 values (min_periods 20), which puts it on the forecast scale, and then clipped at a maximum of 0. The forecast is therefore negative (short) when the 14-day return is below zero, and its size grows with the depth of the decline in usual daily swings, up to -20. It is 0 when the 14-day return is zero or positive, so it never goes long. Code keeps the book flat outside calm markets.

Criterion:
- Horizon: 5 bars
- Main measure: The grid is non-overlapping 5-bar cells of each window, using bars with forecast < 0. On each such bar, take the coin's 5-day return minus its normal 5-day drift (the mean over all its windows, on the same grid), signed short. Main measure: the mean of these values weighted by |forecast|. Its t groups the cases of the same day.
- Supporting check: On the same cases, the mean drift-removed 5-day return of the deeper half (|forecast| above the median) is below that of the shallower half.
- Confirm: The weighted mean short excess return is positive with t >= 2, and the supporting check passes.
- Reject: The weighted mean short excess return is negative with t <= -2, meaning a rebound follows calm swing-scaled declines.
- Inconclusive: Any t between -2 and 2, or a positive t >= 2 when the deeper half does not fall more than the shallower half. A verdict needs cases on at least 30 distinct days.
