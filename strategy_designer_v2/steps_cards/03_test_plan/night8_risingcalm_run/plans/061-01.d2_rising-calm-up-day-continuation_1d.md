Fidelity:
- Situation: a rising, calm market and a one-day rise against the coin's 30-day daily-return standard deviation -> kept: the profile is added by code, and the rise is the 1-day return over the 30-day std, positive part only.
- Comparison: the size of the day in swing units, larger against smaller -> kept: the forecast grows linearly with the rise in usual moves.
- Outcome: a larger rise over the next 5 days -> kept: the book holds each bet 5 bars, and the 5-bar forward return is tested against the forecast size.
- Verdict transfer: yes: the config measures the same scaled rise inside the same profile over the same 5-day horizon, so a confirm or reject carries over to the idea.
Forecast: One component, VolatilityScaledReturnComponent (period 1, vol_period 30, lag 0, vol_lookback 1). It is the day's return divided by the standard deviation of the last 30 daily returns. It is standardised over its past 60 values (min_periods 20), then clipped at 0, so the forecast is long only. It is zero on down or flat days. On up days it is positive and grows linearly with the day's rise in usual moves, capped at +20. The rising-calm profile is added by code, so the book is flat outside it.
Config: 061-01.d2_rising-calm-up-day-continuation_1d_config.json
Profile: rising calm (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 5 bars
- Main measure: The slope of the coin's 5-bar forward return, minus its mean 5-bar return over all windows (holding the coin), regressed on the forecast. It uses grid bars where the forecast is above 0, on a non-overlapping 5-bar grid per window, all coins pooled, with the t taken with cases of one day together.
- Supporting check: On the same cases, the mean excess 5-bar return of the upper half of forecasts minus that of the lower half is above 0.
- Confirm: The slope is positive with t >= 2, and the supporting check passes.
- Reject: The slope is negative with t <= -2.
- Inconclusive: Any slope with |t| < 2, or a positive slope with t >= 2 whose supporting check fails. Fewer than 100 grid cases with a positive forecast is inconclusive whatever the t.
