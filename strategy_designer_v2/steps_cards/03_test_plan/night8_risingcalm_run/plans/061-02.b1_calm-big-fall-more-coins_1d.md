Fidelity:
- Situation: a coin's one-day fall against its 30-day daily-return standard deviation, in a calm market -> kept (the calm profile is added by code; the fall is graded and is zero on up days)
- Comparison: the fall measured in units of the past 30 days' daily-return standard deviation -> kept
- Outcome: a larger fall over the next 5 days, growing with the day's size -> kept (5-bar holding period, short side)
- Verdict transfer: yes: the short size follows the day's fall in 30-day swing units, and inside the calm profile the book holds it for 5 days, which is exactly the claim.
Forecast: The forecast uses VolatilityScaledReturnComponent with period 1, vol_period 30, lag 0 and vol_lookback 1. Its raw value is the day's return divided by the standard deviation of the last 30 daily returns. Standardise (window 60, min_periods 20) puts it on the forecast scale. A clip at max 0 keeps only down days. On a down day the forecast is negative (short), and its size grows linearly with the fall in swing units. On up or flat days it is 0. Outside the calm profile, code keeps the book flat.

Profile: calm (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 5 bars
- Main measure: The sample is the non-overlapping 5-bar grid of each window, taking the bars with forecast < 0. The x value is -forecast (the size of the fall). The y value is the coin's 5-bar forward return minus its mean 5-bar return over all windows, with the sign flipped so that a fall counts positive. The measure is the least-squares slope of y on x and its t, with the cells of one day taken together.
- Supporting check: The mean unusual move of those cases in the short direction must be above 0, with t >= 2, cases of one day pooled.
- Confirm: The slope's t is >= 2 and the supporting check passes (mean unusual move > 0 with t >= 2), before costs.
- Reject: The slope's t is <= -2, meaning larger falls are followed by relative rises. A mean unusual move with t <= -2 (a reversal) also rejects.
- Inconclusive: Any slope t between -2 and 2 is inconclusive. A slope t >= 2 whose check fails is also inconclusive. The test needs at least 100 grid cells with forecast < 0, falling on at least 50 distinct days; with fewer, the result is inconclusive.
