Forecast: The regime detector selects `mean_reversion` only on a bar where the 1-day return is above 0 and the 3-day return is below 0. Every other bar is `unknown`, which is flat, and code keeps the book flat outside falling agitated. Inside the regime the forecast is minus the standardised value of RangeInReturnStdComponent (vol_period 30), which is (high − low) / close / the std of the last 30 daily returns. `standardise` uses window 60 and min_periods 20. The forecast is always negative there (short) and about −10 for a range of usual width. It grows toward −20 as the day's range widens against the 30-day swing, and shrinks toward 0 for a narrow day.
