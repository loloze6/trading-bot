Fidelity:
- Situation: a coin after a 14-day rise, at Thursday's close (UTC) -> kept: a regime fires only on Thursday-close bars whose 14-day return is above 0.
- Comparison: larger two-week rise against smaller two-week rise -> kept: the forecast is graded by the size of the 14-day return.
- Outcome: larger gain over the following Friday and Saturday, long side -> kept: a 2-bar hold from the Thursday close, judged against the coin's normal 2-day drift.
- Verdict transfer: yes: the test measures the same condition, the same grading and the same two-day long outcome that the idea states.
Forecast: The forecast is computed only on Thursday-close bars, where the coming bar is a Friday (WeekdayComponent = 4) and the 14-day return (PriceEvolutionComponent, period 14) is above 0. On those bars the forecast is the 14-day return standardised against its own past 60 values (min_periods 20) and clipped at 0 from below. It is zero for a flat return, grows in proportion to the size of the two-week rise and is capped at +20. On every other bar it is 0: the long is held through Friday and Saturday by the 2-bar holding period, and there is never a short.

Criterion:
- Horizon: 2 bars
- Main measure: On Thursday-close bars with forecast > 0, take each case's 2-bar return (close[t+2]/close[t]-1) minus the coin's mean non-overlapping 2-bar return over all windows. Regress this excess return on the forecast, pooled over coins, and read the slope's t.
- Supporting check: The forecast-weighted mean of the excess 2-bar return over those cases is above 0.
- Confirm: The slope has t >= 2 and the supporting check passes.
- Reject: The slope has t <= -2.
- Inconclusive: A slope with -2 < t < 2, or t >= 2 with a forecast-weighted mean excess return <= 0. The test needs at least 200 cases; fewer cases are inconclusive.
