Fidelity:
- Situation: the coin's return from Monday's close to Thursday's close, read before Saturday -> adapted: the 3-bar return ending at Thursday (lag 1), read at Friday's close in usual moves; a Saturday-only regime condition holds it.
- Comparison: the grading does not come from Friday's own move -> kept: the lagged return and its volatility both stop at Thursday, so Friday's move never enters the forecast.
- Outcome: the coin rises more over Saturday (UTC) the higher that return -> kept: the position runs from Friday's close to Saturday's close, signed and sized by the return.
- Verdict transfer: yes: the forecast is the idea's Monday-to-Thursday return, held only through Saturday, so a confirm or a reject of its relation to Saturday's move is a confirm or a reject of the idea.
Forecast: The forecast is computed only on the bar whose next bar is Saturday, which is Friday's bar; the regime rule uses WeekdayComponent between 4.5 and 5.5. On that bar it is VolatilityScaledReturnComponent with period 3, lag 1 and vol_period 20. That gives close[Thu] / close[Mon] − 1, divided by the 20-day return standard deviation ending Thursday, then standardised over its past 60 values (min 20). It is positive and long after a Monday-to-Thursday rise, negative and short after a fall, and grows linearly with the size of the move. It is 0 on every other day, so the position is held only over Saturday.

- Horizon: 1 bar
- Main measure: Each case is a Friday bar with a non-zero forecast. For each case, take forecast/10 × (Saturday's return close[t+1]/close[t] − 1, minus the coin's mean daily return over all its windows). The measure is the mean over cases. Its t is computed with the cases of one date summed together.
- Supporting check: In a regression of Saturday's excess return on the Friday forecast and on Friday's own return (close[t]/close[t-1] − 1), the forecast's coefficient has the same sign as the main measure.
- Confirm: The main measure is positive with t ≥ 2, and the supporting check's forecast coefficient is positive.
- Reject: The main measure is negative with t ≤ −2.
- Inconclusive: Any t between −2 and 2 is inconclusive. So is a t of 2 or more whose supporting coefficient is not positive. At least 100 distinct Fridays with cases are needed; with fewer, the result is inconclusive.
