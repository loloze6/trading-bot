Fidelity:
- Situation: an up day that ends a run of down days, while the 20-day return is deeply negative -> adapted: the run-break day is kept as an event ("after" made "while", held 1 bar), and "deeply negative" is a regime (20-day return at or below -1 usual 20-day move).
- Comparison: larger fall the deeper the 20-day decline in own swings and the more down days beyond the first -> kept: the product of the 20-day fall in usual moves and (run length - 1).
- Outcome: price falls over the next day -> kept: short, horizon 1 bar.
- Verdict transfer: yes: the component measures the idea's own event and grading, the regime keeps its "only while", and a next-day short tests its stated outcome.
Forecast: The regime detector computes the 20-day return in usual 20-day moves: the 20-day return divided by the 20-day standard deviation of daily returns times sqrt(20). Bars at or below -1.0 go to `trending`, and all other bars are flat. Inside `trending`, the forecast comes from ScaledFallTimesBrokenDownRunComponent (period 20, vol_period 20, max_bars 30). On a day that closes up after a run of n down days, it equals the 20-day fall in usual moves times (n - 1). On every other day it is 0. The value is standardised over its past 60 values (min 20) and negated, so the forecast is short only. Its size grows with the depth of the slide and with the length of the run. It is 0 on any bar that is not a run break, on a break after a single down day, and outside the deep-slide regime. Code adds the falling calm profile and the 1-bar hold.
