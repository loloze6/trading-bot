Fidelity:
- Situation: a day closing up after an unbroken run of down days, in a falling calm market -> kept: the breaking up close (PriorDownRunLossOnUpCloseComponent); the code adds the falling calm profile.
- Comparison: the run's total fall, deep against the coin's usual daily swing ("several times") -> kept: the run's loss in usual daily moves, with the regime set at 3 or more (the most common reading of "several") and the size graded by depth inside it.
- Outcome: the price falls over the next day, more after deeper runs -> kept: a short held 1 bar, sized by the depth.
- Verdict transfer: yes: the test shorts exactly the relief days after deep quiet runs, sized by their depth, over the next day.
Forecast: The forecast uses PriorDownRunLossOnUpCloseComponent (side "down", base "usual_moves", window 30, exclude_current 1). On a day that closes up, it reads the total loss of the down run that ended yesterday, counted in the mean absolute daily moves of the 30 days ending yesterday. On every other day it reads 0. The regime detector selects mean_reversion only when that loss is 3 or more usual moves, and every other bar is flat. Inside that regime, the same loss is standardised against its own last 60 values with target 1. The target is set low because the history is mostly zeros, so a deep run does not hit the cap on every case. The value is then negated. The forecast is always negative (short only) and grows in size with the run's depth, up to the -20 cap. It is zero outside deep-run relief days and outside the falling calm profile.
