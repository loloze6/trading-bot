Fidelity:
- Situation: in a falling, agitated market, the first up day ending a run of consecutive down days -> kept: the profile is added by code, and the run break is a regime rule (an up close after 2 or more down closes).
- Comparison: the run's fall against the usual daily swing of the last 30 days -> kept: the run's loss in 30-day standard deviations of daily returns grades the short.
- Outcome: the coin's close falls over the next day, more after deeper runs -> kept: a short held 1 bar, sized by that depth.
- Verdict transfer: yes: the book is short only on run-break days in the profile, scaled by run depth, so its next-day result is the idea's claim.
Forecast: On a bar that is the first up close after 2 or more consecutive down closes (the regime), the forecast is minus the run's total fall in 30-day daily-return standard deviations (`PriorDownRunLossOnUpCloseComponent`, base "std", window 30), standardised. The forecast is zero on every other bar, and code adds the falling-agitated profile. It is never positive. It is graded: a deeper run gives a larger short, up to the cap. The raw reading is 0 on most bars, which dilutes the standardise base. Standardise therefore uses target 2.5 (a quarter of bars carry a reading on a symmetric walk), so a typical run break sits near -10 rather than at the cap.

Criterion:
- Horizon: 1 bar
- Main measure: On bars with a nonzero forecast, the next-day return minus the coin's mean daily return over all windows, signed short (the negated excess). Its mean and t are computed with cases on the same day summed together.
- Supporting check: The slope of that short-signed excess return on the absolute forecast is above 0 (deeper runs fall more).
- Confirm: The mean short-signed excess return is above 0 with t ≥ 2, and the supporting slope is above 0.
- Reject: The mean short-signed excess return has t ≤ -2 (the day after a run break rises more than the coin's usual day).
- Inconclusive: A t between -2 and 2, or a t ≥ 2 with a slope ≤ 0, is inconclusive. So is any result with fewer than 30 cases, or cases on fewer than 30 distinct days.
