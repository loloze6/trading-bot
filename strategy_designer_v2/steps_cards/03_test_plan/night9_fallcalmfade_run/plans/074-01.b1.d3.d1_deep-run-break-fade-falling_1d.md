Fidelity:
- Situation: in a falling market, the first up day after a run of consecutive down days -> kept: the profile "falling" is added by code, and a regime rule selects up closes that end a run of at least 2 down closes.
- Comparison: the fall grows faster than the run's depth (the run's return against the usual daily swing over 30 days) -> adapted: the run's loss in 30-day daily-return standard deviations is graded convexly, so shallow runs give almost nothing and deep runs give most of the size.
- Outcome: the coin's close falls over the next day -> kept: a short held for 1 bar.
- Verdict transfer: yes: the test shorts exactly those up days, sized by the stated depth, over the stated one day, so its result is the idea's result.
Forecast: The regime detector counts the down closes that today's up close breaks (`PriorDownRunOnUpCloseComponent`). When that run is 2 bars or longer, the bar is `mean_reversion`; on every other bar the book is flat. Inside that regime the forecast comes from `PriorDownRunLossOnUpCloseComponent` (side "down", base "std", window 30): the run's total loss divided by the standard deviation of the last 30 daily returns. That loss is standardised over its own past 60 values. The target is 2.5, because the stored history is non-zero only on the roughly one bar in four that ends a down run; this puts a typical run-breaking day near 10. The value is then negated, so the forecast is short only and never above 0. Finally `signed_power` is applied with exponent 3 and pivot 20, the strongest graded dead zone allowed. A run of average depth gives about -2.5, half that depth about -0.3, and a run at twice the usual depth or more reaches -20. The forecast is 0 outside the situation and outside the falling profile.

Criterion:

- Main measure: Take the cases (bars with forecast below 0) in the top third by |forecast|, all coins and windows together. Measure the next-day return close[t+1]/close[t]-1 minus the coin's mean daily return over all windows, signed for a short, and take its mean. The t is computed with the cases of the same day taken together.
- Supporting check: The same unusual move, top third minus bottom third of cases by |forecast|, must be above 0 (the fall grows with depth).
- Confirm: The top-third mean unusual short-side move has t ≥ 2, and the top-minus-bottom difference is above 0.
- Reject: The top-third mean unusual short-side move has t ≤ -2.
- Inconclusive: A top-third t between -2 and 2 is inconclusive. So is a top-third t ≥ 2 when the top-minus-bottom difference is 0 or below. The test also needs at least 30 top-third cases on at least 30 distinct days; fewer is inconclusive.
