- Situation: in a falling agitated market, the first up day after a run of consecutive down days -> kept: a regime on the run-breaking up close (two or more down days); the profile is added by code.
- Comparison: the run's depth, its loss over the down days against the usual daily swing of the last 30 days -> kept: the run's loss in mean absolute daily moves over 30 days, which sizes the short.
- Outcome: the close falls over the next day, more than linearly with depth, mostly after the deepest runs -> kept: a 1-bar short whose size grows with the square of the standardised depth.
- Verdict transfer: yes: the book is short only on run-breaking up days, sized convexly by depth, for one day, which is exactly the claim.
Forecast: The forecast is zero except on an up close that ends a run of 2 or more down closes. On such a bar it is short and graded by the run's depth: the run's loss divided by the mean absolute daily move of the last 30 days (`PriorDownRunLossOnUpCloseComponent`, side "down", base "usual_moves", window 30, max_bars 30). - Scaling: the depth is standardised against its own last 60 stored values (target 2.5, cap 20). Because the history holds zeros on non-break days, a target of 2.5 puts a typical run near 10 instead of at the cap. - Shape: the value is negated, then `signed_power` (exponent 2, pivot 10) is applied, so shallow breaks are damped towards 0 and deep runs are amplified. It is then clipped at 0 from above, so the forecast is never long. - Limits: the forecast is always zero or negative. Code keeps the book flat outside the falling agitated profile.
