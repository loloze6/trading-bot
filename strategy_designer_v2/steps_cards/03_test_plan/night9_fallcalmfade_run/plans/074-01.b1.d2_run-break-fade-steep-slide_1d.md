Fidelity:
- Situation: in a falling market, the first up day after a run of consecutive down days -> kept: a regime. The 60-day return is below -10 % (the profile convention for "falling"), and the day is an up close that ends a run of at least 2 down closes.
- Comparison: the run's fall against its usual daily swing over the last 30 days, and the depth of the 20-day return -> kept: graded by the run's loss in 30-day return standard deviations and by the 20-day fall.
- Outcome: the coin's close falls over the next day -> kept: a short held for 1 bar.
- Verdict transfer: yes: the book shorts only on run-ending up days in falling markets, sized by the two depths, so its next-day result is the idea's claim.
Forecast: The forecast is computed only on a bar that meets two conditions. The coin's 60-day return is below -10 %, and the day closes up after at least 2 consecutive down closes. On every other bar the forecast is 0. On a qualifying bar the forecast is the equal-weight mean of two terms. The first term is the run's total loss in standard deviations of the 30 daily returns before the bounce day (PriorDownRunLossOnUpCloseComponent, base "std", window 30, exclude_current 1). It is standardised with target 2.5 instead of 10, because the component is 0 on most bars and would otherwise sit at the cap. It is then negated. The second term is the 20-day return in percent, standardised and clipped at 0 from above. Both terms are 0 or negative, so the forecast is short-only. It grows more negative as the run's fall deepens against the usual swing and as the 20-day return deepens.

Side: short only (the brief): each component's forecast capped at 0 by step 3's code
Criterion:
- Horizon: 1 bar
- Main measure: Each case is a bar with forecast < 0. On each case, take the coin's next-day return minus its mean daily return over all windows, with the sign flipped for the short. The measure is the mean of this excess over the cases, with its t computed with cases of the same day taken together.
- Supporting check: The same excess is compared between halves of the cases split at the median absolute forecast. The mean in the larger-forecast half minus the mean in the smaller half must be above 0.
- Confirm: The mean excess short return is above 0 with t >= 2, and the supporting check difference is above 0.
- Reject: The mean excess short return is below 0 with t <= -2.
- Inconclusive: Any t between -2 and 2, or a confirming t with the check failing, is inconclusive. At least 100 cases (bars with forecast < 0) are required across the coins, else the result is inconclusive.
