Fidelity:
- Situation: falling calm market; a day closing up after an unbroken run of down days -> adapted: the profile is added by code, and the run-break day is a regime (prior down run of at least 1 on an up close).
- Comparison: the longer that run of down days -> adapted: graded, so the short grows with the run length (sigmoid of the count, then standardised).
- Outcome: a fall over the next day, larger after longer runs -> kept: short for 1 daily bar.
- Verdict transfer: yes: the test shorts exactly the run-break days in a falling calm market, sized by run length, for one day.
Forecast: The regime detector reads `PriorDownRunOnUpCloseComponent` (max_bars 30). Its value is the length of the down run that today's up close breaks, and 0 on any other bar. Bars where it is at least 1 go to `mean_reversion`, and every other bar is flat. Inside that regime, the same component is stored as sigmoid(n). That stored value is 0.5 on ordinary bars and 0.73, 0.88, 0.95 and 0.98 for runs of 1 to 4 days. It is then standardised over its 60 past values and negated. The result is a short of about -13 after a 1-day run, -16 after a 2-day run and -17 after a 3-day run, and the size keeps growing with the run. The forecast is never positive, it is zero outside run-break days, and code adds the falling-calm profile.

Criterion:
- Horizon: 1 bar
- Main measure: A case is a bar with forecast below 0. For each case, take the coin's next-day return (close[t+1]/close[t]-1) minus the coin's mean daily return over all windows, with the sign flipped to the short direction. Cases on the same day across coins are summed into one day. The measure is the mean of this value and its t.
- Supporting check: Run length comes from `last_history_value` (sigmoid of the run) or is recomputed from closes. Compare the next-day excess return on cases with runs of 3 or more against cases with runs of 1 to 2, by Welch t, as longer minus shorter. The check passes when that difference is below 0.
- Confirm: The main measure is above 0 with t ≥ 2 and the supporting check passes.
- Reject: Either the main measure is below 0 with t ≤ -2, meaning run-break days are followed by rises beyond the drift. Or the longer-minus-shorter difference is above 0 with t ≥ 2.
- Inconclusive: Any result with the main t between -2 and 2. Also a main t of 2 or more with a longer-minus-shorter difference of 0 or above, or fewer than 150 cases on fewer than 80 distinct days.
