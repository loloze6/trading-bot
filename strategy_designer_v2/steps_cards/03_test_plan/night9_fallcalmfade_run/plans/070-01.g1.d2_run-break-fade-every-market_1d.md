- Comparison: the fall is larger the more down days the run held beyond the first, and near zero after a single down day -> kept: the forecast is the run's down days beyond the first, so it is 0 after a single down day

Forecast: The regime is active only on a day that closes up right after one or more down closes. The run is measured by `PriorDownRunOnUpCloseComponent` (side "down", form "count") being at least 1; every other bar is flat. Inside the regime, the same component with form "beyond_first" gives the number of down days in the broken run minus one. It is standardised against its own past 60 values with target 1, because it is 0 on most days and its mean absolute value is about 0.25. It is then negated. So the forecast is 0 after a single down day and about -4 after two. It is about -8 after three, about -12 after four, and so on down to the cap of -20. It is never positive, which matches the brief's short-only rule.
