- Situation: in a falling market, an up day that ends a run of down days -> kept: a regime is active only on a close above the prior close that ends a down run. The falling profile is added by code.
- Comparison: the larger the price drop over the run, the larger the next fall -> kept: the short position is graded by the run's loss in percent.
- Outcome: the price falls over the next day -> kept: each bet is held 1 bar (1 day) and judged against the coin's drift.
- Verdict transfer: yes: the test measures the next-day move after each run break and its scaling with the run's loss, exactly as the idea states.
Forecast: The forecast is zero except on a day that closes up after one or more down closes. On that day it is short, sized by the run's loss in percent from the run's first close to its last down close (`PriorDownRunLossOnUpCloseComponent`, side "down", base "percent", max 30 bars). The loss is standardised over 60/20 and negated. It is averaged with weight 1 against a weight-3 companion, the same class with side "up", which is exactly 0 on every up close. This keeps target 10 while scaling the sparse signal down by four, so break days spread over the graded range instead of sitting at the cap. A deeper run gives a larger short; a shallow run gives a short near zero. The forecast is never positive. The code adds the falling profile, so the book is flat when the 60-day return is -10 % or above.
