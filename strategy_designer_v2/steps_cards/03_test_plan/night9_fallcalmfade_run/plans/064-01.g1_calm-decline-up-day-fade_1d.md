Fidelity:
- Situation: in a falling, calm market, a coin's up day, its rise in units of its 20-day daily swing -> kept: the falling-calm profile is added by code, the one-day return over the 20-day return standard deviation is clipped to up days and zero otherwise.
- Comparison: the giveback grows with the rise's size in swing units, across ordinary and moderate rises -> kept: the short is graded linearly by the scaled rise, with no dead zone.
- Outcome: a fall over the next three days -> kept: each short bet is held 3 bars.
- Verdict transfer: yes: the test measures the scaled up day, its graded fade and the 3-day fall inside the falling-calm profile, as the idea states them.
Forecast: The indicator is VolatilityScaledReturnComponent with period 1 and vol_period 20: today's return over the standard deviation of the last 20 daily returns. It is standardised over 60 past values (min_periods 20) and clipped at 0, so only up days count. It is then negated. The forecast is negative (short) on up days and grows linearly in size with the rise measured in usual daily moves. It is zero on down and flat days. It is never positive. It applies on every bar inside the falling-calm profile, which code adds; the book is flat outside the profile.

Profile: falling calm (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 3 bars
- Main measure: The sample is the non-overlapping 3-bar grid of each window, on cases where the forecast is below 0. On each case, take the position size (-forecast / 10) times minus the coin's unusual 3-bar return (close[t+3] / close[t] - 1, minus the coin's mean 3-bar return over all windows). The measure is the t of the mean of these values, with the cases of one day summed together.
- Supporting check: On the same cases, the least-squares slope of the drift-removed fade, -(unusual 3-bar return), on the size of the forecast must be above 0. A positive slope means the giveback grows with the scaled rise.
- Confirm: The main measure's t is 2 or more, and the supporting slope is above 0.
- Reject: The main measure's t is -2 or less: scaled up days are followed by rises beyond drift. Or the supporting slope's t is -2 or less: the fade shrinks as the rise grows.
- Inconclusive: Any other result is inconclusive. This includes a main t between -2 and 2, and a main t of 2 or more with a slope at or below 0 whose t is above -2. It also includes fewer than 30 independent cases (distinct days) across coins and windows.
