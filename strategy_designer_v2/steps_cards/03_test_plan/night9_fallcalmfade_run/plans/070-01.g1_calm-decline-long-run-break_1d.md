Fidelity:
- Situation: a falling, calm market (the brief's profile); an up day that ends a run of down days -> kept: the profile is added by code, and the run break is a regime rule on `PriorDownRunOnUpCloseComponent` >= 1.
- Comparison: the fall grows with the down days beyond the first, and a single down day gives almost none -> replaced: no catalogue forecast source grades the position by the run's length.
- Outcome: a fall over the next day, short -> kept: horizon 1 bar, short side only.
- Verdict transfer: no: without a graded run-length forecast, the test cannot show that the fall grows with the run, or that a single-day break carries almost nothing.
Reason: The run length is in the coin's own closes, but only `PriorDownRunOnUpCloseComponent` computes it, and the catalogue classes it as a regime measure, not a forecast source. It is 0 on most bars, so `standardise` puts every run-break bar near its cap of 20, and the position would not follow the run's length. No other component or combination grades the forecast by the count of down days ended by today's up close.
