Fidelity:
- Situation: a close near its 20-day high, in a calm market -> kept: the close's proximity to the 20-day high, graded; the calm profile is added by code.
- Comparison: the nearer the close to the high, the larger the rise -> kept: the position grows with proximity, and the test reads the gain against proximity.
- Outcome: a rise over the next 3 days -> kept: each bet is held 3 daily bars and judged on the 3-day return.
- Verdict transfer: yes: the forecast is the idea's proximity graded on every calm bar, so a confirm or a reject of the size-to-return relation is the idea's.
Forecast: The forecast is the proximity of the close to its 20-day high, using bar highs with today's bar included. The proximity is 1 / (1 + percent distance below the high). It is standardised over its past 60 values (minimum 20), so it averages about +10 and is capped at +20 at the high. It is always positive (long only) and grows continuously as the close nears the high. It stays small, never exactly 0, when the close is far below the high. Outside the calm profile the code keeps the book flat.

Profile: calm (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 3 bars
- Main measure: On a non-overlapping 3-bar grid per window, take each bar where the book is in profile (forecast above 0). Regress the coin's 3-day forward return minus the coin's mean 3-day return over all windows on the forecast. Report the slope's t with the number of cases.
- Supporting check: On the same grid cases, take the mean excess 3-day return of the top third of forecasts minus that of the bottom third (Welch t). It must be above 0.
- Confirm: The slope's t is 2 or more and the top-minus-bottom difference is above 0.
- Reject: The slope's t is -2 or less.
- Inconclusive: A slope t between -2 and 2, or a t of 2 or more with the top-minus-bottom difference at or below 0. At least 300 grid cases are needed, else the result is inconclusive.
