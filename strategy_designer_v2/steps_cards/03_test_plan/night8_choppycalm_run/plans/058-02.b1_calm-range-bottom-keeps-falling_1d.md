Fidelity:
- Situation: a choppy, calm market and a close near the bottom of its 20-day high-low range -> kept: the code adds the choppy calm profile, and the close's position in its 20-day high-low range measures nearness to the bottom.
- Comparison: the nearer the bottom, the larger the fall -> kept: the short forecast grows linearly as the close nears the 20-day low, and is 0 at the range's middle.
- Outcome: the coin falls over the next 5 days -> kept: each short bet is held for 5 daily bars.
- Verdict transfer: yes: the forecast measures the stated nearness and holds the stated 5-day fall, so a confirm or a reject on it transfers to the idea.
Forecast: The forecast uses one indicator, the close's position in its 20-bar high-low range (Donchian, `form` "position", bar t included). It reads -1 at the range low, 0 at the middle and +1 at the high. The position is standardised against its own last 60 values and then clipped at 0, so only the bottom half of the range counts. Above the middle the forecast is 0 (flat). Below the middle it is negative (short), and it grows in size the nearer the close sits to the 20-day low. The code limits the book to choppy calm bars.

Criterion:
- Horizon: 5 bars
- Main measure: Use the non-overlapping 5-bar grid of each window, on grid bars with forecast < 0. Regress the coin's 5-bar forward return, minus its mean 5-bar return over all windows, on the forecast. Report the OLS slope and its t, taking cases on the same day together.
- Supporting check: On those same grid bars, the mean drift-adjusted 5-bar forward return is below 0.
- Confirm: The slope's t is 2 or more (a more negative forecast is followed by a lower excess return), and the supporting check passes.
- Reject: The slope's t is -2 or less (bars nearer the low are followed by higher excess returns).
- Inconclusive: A slope t between -2 and 2 is inconclusive. So is a confirming slope whose check fails. So is any result from fewer than 30 grid cases with forecast < 0, or cases falling on fewer than 20 distinct days.
