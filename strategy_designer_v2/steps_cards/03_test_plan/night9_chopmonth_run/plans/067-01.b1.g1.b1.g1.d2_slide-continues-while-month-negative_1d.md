- Situation: a fall over the past 30 days, in a choppy market, only while the 30-day return is still negative -> adapted: the choppy market (60-day return between -10 % and +10 %, the profile convention) and the negative 30-day return form a regime; inside it, the position is graded by the depth of the 30-day fall.
- Comparison: the deeper the remaining monthly fall, the larger the further fall -> kept: the short grows with the size of the negative 30-day return.
- Outcome: a further fall over the next 10 days, ending once the month's return turns up -> kept: the book is short over a 10-bar horizon, and the forecast is 0 once the 30-day return is at or above 0.
- Verdict transfer: yes: the forecast is short only in the idea's situation, sized by the idea's own measure, over its own horizon.
Forecast: Two conditions decide when a position exists. A regime rule requires the 60-bar return to be between -10 % and +10 % (choppy) and the 30-bar return to be below 0. When both hold, the forecast comes from the 30-bar percent return (`PriceEvolutionComponent`, period 30). It is standardised over 60 past values, and a clip at max 0 keeps only the fall. The forecast is negative (short), grows with the depth of the 30-day fall, and nears 0 as the month's return nears 0. On every other bar it is 0: outside the choppy market, or when the 30-day return is 0 or above. It is never positive.
