Fidelity:
- Situation: the coin's close sits below its close of 30 days earlier, in a choppy agitated market -> kept: the 30-bar percent return, clipped at 0 so the book is flat after a rise; the profile is added by code.
- Comparison: the depth of the fall, as a plain percent of the close 30 days earlier -> kept: the position grows with the size of that percent fall.
- Outcome: the price falls further over the next 7 days -> kept: a short position, held 7 bars.
- Verdict transfer: yes: the forecast is the idea's own graded fall, short only and inside the idea's profile, so the result transfers both ways.
Forecast: One indicator, the coin's 30-bar percent return (PriceEvolutionComponent, period 30). The engine standardises it against its own past 60 values (target 10, cap 20), then clips it at a maximum of 0. The forecast is 0 whenever the close is at or above its close of 30 bars earlier. It is negative (short) when the close is below that level, and it grows in size with the depth of the fall, up to -20. Code keeps it at 0 outside the choppy agitated profile.

Profile: choppy agitated (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 7 bars
- Main measure: Sample the bars at positions 0, 7, 14, ... of each window where the forecast is below 0. For each one, take the coin's 7-bar return minus the coin's mean 7-bar return over all windows, with the sign flipped for the short side. Average these, weighted by |forecast|, with a t that takes the cases of one day together.
- Supporting check: On the same cases, the excess 7-bar return of the deeper half (by |forecast|) minus that of the shallower half is below 0, so a deeper fall is followed by a larger fall.
- Confirm: The weighted mean short-side excess return is above 0 with t >= 2, and the supporting check passes.
- Reject: The weighted mean short-side excess return is below 0 with t <= -2. After the fall, the coin beats its drift.
- Inconclusive: Any t between -2 and 2 is inconclusive. So is a confirming main measure whose supporting check fails. Fewer than 30 independent cases is also inconclusive, whatever the t.
