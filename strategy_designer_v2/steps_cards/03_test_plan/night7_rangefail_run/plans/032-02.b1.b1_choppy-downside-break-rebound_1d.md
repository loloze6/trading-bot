- Situation: in a choppy market, the daily close is below the lowest low of the prior 20 days -> kept: the profile line supplies "choppy", and a regime rule fires when the close is below the prior 20-day low.
- Comparison: how far the close sits below that low -> kept: the percent depth below the prior 20-day low grades the forecast.
- Outcome: price rises over the next day, more for deeper breaks -> kept: a long position held for 1 bar, sized by the depth.
- Verdict transfer: yes: the test measures the idea's own break, depth and one-day rise inside the choppy profile.
Forecast: One component, `DistanceFromHighComponent` with period 20, source "high", extreme "low" and exclude_current 1, gives the close's percent distance from the lowest low of the prior 20 bars. The regime detector reads that raw value. When it is below 0 (the close is under the prior low), the bar is `mean_reversion`. Every other bar is `unknown`, which holds no position. Inside the regime, the same component is standardised over 60 bars and negated. The forecast is therefore positive and grows linearly with the depth below the low: 0 at the low, larger the deeper the close. It is never negative, and it is 0 outside a break. Step 3's code adds the choppy profile (60-day return between -10 % and +10 %).
