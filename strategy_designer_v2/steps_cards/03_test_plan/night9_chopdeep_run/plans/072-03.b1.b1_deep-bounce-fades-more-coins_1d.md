Fidelity:
- Situation: in a choppy market, a day that closed up -> kept: choppy is the brief's profile; the up close is a regime (close above the prior close).
- Comparison: the close's distance below the 20-day high, in 20-day daily-return standard deviations -> kept: VolatilityScaledDistanceFromHigh (20, 20), graded by depth.
- Outcome: a larger fall over the next 10 days, the deeper the close -> kept: a short position sized by depth, held 10 bars.
- Verdict transfer: yes: the config measures the stated depth on choppy up days and bets on the stated 10-day fall, so its result is the idea's result.
Forecast: On each daily bar where the close is above the previous close, the forecast reads how far the close sits below the highest close of the last 20 bars, today's close included. That distance is a percent of the high divided by the standard deviation of the last 20 daily returns. It is standardised over its past 60 values, so a usual depth gives about -10 and the cap is -20. The forecast is clipped at 0 from above, so it is short only. It is 0 at the 20-day high and grows more negative, in a continuous way, as the close sits deeper. On down or flat days the regime is null and the forecast is 0. Outside the choppy profile, the code that adds the profile keeps the book flat.

Side: short only (the brief): each component's forecast capped at 0 by step 3's code
Profile: choppy (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 10 bars
- Main measure: Cases are the bars on each window's 10-bar grid (positions 0, 10, 20, ...) that are up days in the regime with a forecast below 0. For each case, take the coin's 10-day return minus the coin's mean 10-day return over all windows (holding the coin), then multiply by the forecast / 10. The measure is the mean of these products, before costs, with a t computed with each day's cases summed into one.
- Supporting check: Split the cases at the median of |forecast|. The deeper half's mean 10-day return minus drift, minus the shallower half's, must be below 0 (Welch t of -1 or less).
- Confirm: The main measure is above 0 with t ≥ 2, and the supporting check passes.
- Reject: The main measure is below 0 with t ≤ -2.
- Inconclusive: Any t between -2 and 2, or a confirming main measure whose check fails. Fewer than 30 distinct case days is inconclusive whatever the t.
