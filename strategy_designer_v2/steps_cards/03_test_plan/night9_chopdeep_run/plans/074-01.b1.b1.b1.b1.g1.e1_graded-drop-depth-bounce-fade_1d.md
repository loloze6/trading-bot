Fidelity:
- Situation: a wide up day in a falling market -> kept: a regime selects up days (1-day return above 0) whose range is above its 20-day mean daily range; the falling profile is added by code.
- Comparison: deeper fall over the 5 days before the up day, in usual 5-day moves -> kept: the 5-day return ending the day before, over the 20-day daily return std times sqrt(5), grades the short.
- Outcome: price falls over the next day -> kept: short for 1 bar, sized by that depth.
- Verdict transfer: yes: the test shorts only wide up days in falling markets, sized by the prior 5-day fall, and judges the next day's move.
Forecast: The forecast is active only on an up day (1-day return above 0) whose high-low range is above the mean daily range of the last 20 days, bar t included. On every other bar it is 0. Inside that situation, the forecast reads the coin's 5-day return ending the day before the up day (close[t-1] / close[t-6] - 1). It divides that return by the usual 5-day move, which is the 20-day standard deviation of daily returns ending at t-1, times sqrt(5). The result is standardised over its last 60 values (target 10, cap 20) and clipped at a maximum of 0. So the forecast is short and grows with the depth of the prior 5-day fall in usual moves. It is 0 after a flat or rising week, and never long. The falling profile is added by code.
