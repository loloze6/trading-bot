Fidelity:
- Situation: in a falling market, an up day whose 5-day return including that day is still negative -> kept: the regime holds only bars that close above the prior close with a negative 5-day return; the code adds the falling profile.
- Comparison: the 5-day loss against the coin's own daily swing over the past 20 days -> kept: the 5-day return divided by the 20-day standard deviation of daily returns (the constant √5 cancels under standardise).
- Outcome: a fall over the next day, larger the deeper that loss -> kept: a one-day short graded by the scaled loss, held 1 bar.
- Verdict transfer: yes: the test measures exactly the stated bars, the stated strength and the next-day move.
Forecast: The regime detector selects only bars where the 1-day return is above 0 and the 5-day return is below 0. On those bars the forecast is the 5-day return in units of the 20-day daily return standard deviation (`VolatilityScaledReturnComponent`, period 5, vol_period 20), standardised over its past 60 values (min 20). - The raw value is negative inside the regime, so the forecast is a short. - The short grows linearly with how many usual swings the coin is down over the week, so it is near 0 when the loss is shallow. - The forecast is 0 on every other bar, and outside the falling profile, which the code adds.
