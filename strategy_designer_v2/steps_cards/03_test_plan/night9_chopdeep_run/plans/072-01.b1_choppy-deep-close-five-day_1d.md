Fidelity:
- Situation: in a choppy market, the close's distance below its 20-day high, in units of the 20-day standard deviation of daily returns -> kept (the choppy profile is added by code)
- Comparison: deeper closes against shallower closes below the high -> kept: the forecast is graded by depth, and the criterion compares across depths
- Outcome: a larger fall over the next five days the deeper the close, so short -> kept: 5-bar horizon, short only
- Verdict transfer: yes: the forecast is the idea's own depth measure, short and graded, held for its five days, so a confirm or reject reads straight onto the idea.
Forecast: The component is VolatilityScaledDistanceFromHighComponent with period 20, vol_period 20, source "high", exclude_current 0 and base "level". It gives (close − 20-day highest high) / that high / std of the last 20 daily returns. That is never positive: 0 at the high, more negative the deeper the close sits below it in usual daily moves. It is standardised over its past 60 values (min 20), so the average depth gives about −10, capped at −20. It is then clipped at max 0 so the book stays short only. The forecast is 0 at the high and grows smoothly short with depth. It is ungated, and the code keeps the book flat outside the choppy profile.

Side: short only (the brief): each component's forecast capped at 0 by step 3's code
Profile: choppy (the idea): no position outside it, by step 3's code (common/market_profile.md)
Criterion:
- Horizon: 5 bars
- Main measure: Use non-overlapping 5-bar grid cells of each window where the forecast is below 0. Regress the coin's 5-bar forward return, minus its normal 5-bar drift (all windows together), on the forecast. Report the slope's t. The idea predicts a positive slope: a more negative forecast is followed by a more negative excess return.
- Supporting check: Among those cases, the mean 5-bar excess return of the deepest third of forecasts must be below that of the shallowest third.
- Confirm: Slope t ≥ 2 and the supporting check passes.
- Reject: Slope t ≤ −2: deeper closes are followed by relatively larger rises.
- Inconclusive: Any slope t between −2 and 2, or a confirming t whose supporting check fails. The test needs at least 100 grid cases with a nonzero forecast, falling on at least 60 distinct days; fewer cases is inconclusive.
