Forecast: The forecast is active only on choppy bars. A bar is choppy when the unsmoothed 30-bar efficiency ratio is at most 0.30, the 30-bar return is above 0 and the 7-bar return is above 0. On every other bar it is flat. Inside the regime the forecast is the 7-bar return divided by the 30-bar standard deviation of daily returns times sqrt(7). This value is standardised against its past 60 values, clipped at 0 so it stays long only, and then squared in a signed way (exponent 2, pivot 10). Small scaled rises therefore give almost no position. Large ones give a position that grows faster than the rise does. The forecast is never negative.
