Fidelity:
- Situation: past 30 days choppy (little net progress against the sum of daily moves), and the 7-day move points the same way as the 30-day net move -> kept: a regime where the raw 30-day efficiency ratio is below 0.3 (Kaufman's usual chop level, since the idea gives no number) and the 7-day and 30-day returns have the same sign; flat outside it.
- Comparison: the 7-day move counted in 30-day daily swings -> kept: the 7-day return divided by (30-day daily return std x sqrt 7).
- Outcome: a move the same way over the next 7 days, larger for a larger scaled move, while the chop and the agreement last -> adapted: "after" made "while"; the position is graded by the scaled move and held over the 7-day horizon.
- Verdict transfer: yes: the forecast exists only in the stated situation, follows the scaled weekly move's sign and size, and is judged on the next 7 days' move.
Forecast: The regime detector selects `mean_reversion` (used only as a label) on bars where three things hold. The raw 30-bar efficiency ratio is below 0.3, the 7-bar return is positive, and the 30-bar return is positive. The same applies when both returns are negative. On every other bar the forecast is 0. Inside the regime, the forecast is the 7-bar return divided by (std of the last 30 daily returns x sqrt 7), standardised over its last 60 values (target 10, cap 20). Because the regime requires agreement, the forecast takes the month's sign: long after an up week in an up month, short after a down week in a down month. Its size grows linearly with the scaled weekly move.

Criterion:
- Horizon: 7 bars
- Main measure: On each window's non-overlapping 7-bar grid, a case is a grid bar with a non-zero forecast. For each case, take the coin's 7-bar forward return minus the coin's mean 7-bar return over all windows, times sign(forecast). Average these weighted by |forecast|, with cases on the same day summed into one. Report its t and the number of days.
- Supporting check: Split the cases at the median of |forecast|. The mean signed excess return of the upper half minus that of the lower half must be above 0.
- Confirm: The weighted mean is positive with t >= 2, and the supporting check is above 0.
- Reject: The weighted mean is negative with t <= -2.
- Inconclusive: Any t between -2 and 2 is inconclusive. So is t >= 2 with the supporting check at or below 0. So is any result from fewer than 50 cases.
