Fidelity:
- Situation: XMR's one-day return, measured against its 30-day daily volatility -> kept
- Comparison: the 5-day volatility against the 30-day volatility, which scales the reversal -> kept
- Outcome: the price moves back against the day's move over the next day -> kept
- Verdict transfer: yes: the forecast is exactly the vol-scaled daily move times the 5-day-to-30-day volatility ratio, faded over one day.
Forecast: The forecast uses one component, RecentToPriorVolatilityWeightedReturnComponent (period 1, vol_period 5, base_period 30, base_lag 0, return_scale "base_std"). Its raw value is the day's return divided by the 30-day daily volatility, times the 5-day volatility over the 30-day volatility. It is standardised over 60 bars (min_periods 20), then negated. After a down day it is long, after an up day it is short, and it is 0 when the day's move is 0. Its size grows with how many usual moves the day covered, and with how turbulent the last 5 days were against the month. A lone move in a calm stretch therefore gives a small position. The forecast applies on every bar with no regime, and it is capped at ±20.

Criterion:

- Main measure: For each bar, take XMR's next-bar return minus its mean daily return over all windows. Regress it on that bar's forecast, using every bar, all windows pooled, no return crossing a window. Report the slope's t.
- Supporting check: The book's timing gain is positive. That gain is its mean daily return minus the gain from the market's own rise (position × the coin's mean daily return).
- Confirm: The slope is positive with t ≥ 2, and the timing gain is above 0.
- Reject: The slope is negative with t ≤ -2.
- Inconclusive: Any slope with |t| < 2 is inconclusive. So is a positive slope with t ≥ 2 whose timing gain is not positive. At least 1000 bars with a non-zero forecast are required; fewer is inconclusive.
