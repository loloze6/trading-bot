Forecast: The forecast is the day's return divided by the standard deviation of the last 30 daily returns, using VolatilityScaledReturnComponent with period 1 and vol_period 30. It is negated and clipped at 0. The result is positive only on down days, and it grows linearly with the fall's depth in usual daily moves. It is 0 on up days and flat days, so the book never shorts. Standardise is set to target 5 rather than 10, because the raw value is 0 on about half the bars. With target 10, an ordinary fall would sit at the +20 cap. With target 5, a fall of about one usual move gives roughly +10, and the forecast stays graded up to about two usual moves.
