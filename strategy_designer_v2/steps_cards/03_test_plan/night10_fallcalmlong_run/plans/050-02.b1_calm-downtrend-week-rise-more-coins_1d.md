Criterion:
- Horizon: 3 bars
- Main measure: The unusual move over 3 bars on the cases, measured on the non-overlapping 3-bar grid of each window. A case is a forecast > 0. The unusual move is the coin's 3-day return from the case bar minus its normal 3-day drift over all windows. The t is computed with the cases of one day taken together.
- Supporting check: The cases in the upper half of the positive forecasts (by the coin's median) minus those in the lower half, in mean unusual 3-day move, Welch's t.
- Confirm: The main measure has a mean unusual move > 0 with t >= 2, and the upper-minus-lower difference is > 0.
- Reject: The main measure has a mean unusual move < 0 with t <= -2, or the upper-minus-lower difference has Welch t <= -2.
- Inconclusive: Any other result, or fewer than 30 distinct case days across all coins and windows. This includes a main-measure t between -2 and 2, and a confirmed main measure with an upper-minus-lower difference <= 0 and t above -2.
