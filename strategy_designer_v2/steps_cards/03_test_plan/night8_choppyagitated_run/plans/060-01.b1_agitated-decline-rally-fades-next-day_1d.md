Fidelity:
- Situation: a one-day rise, in a falling agitated market -> adapted: rise graded by its size in 30-day return standard deviations, zero on down days; the profile is added by code.
- Comparison: the rise against the standard deviation of daily returns over the past 30 days -> kept
- Outcome: a larger fall over the next 1 day -> kept
- Verdict transfer: yes: the forecast is a short that grows with the scaled rise and is held one day, so the next day's return tests exactly the claim.
Forecast: One component, `VolatilityScaledReturnComponent` with `period` 1 and `vol_period` 30. It gives the day's return divided by the standard deviation of the last 30 daily returns. It is standardised over its past 60 values, clipped at 0 so that only up days count, then negated. The forecast is 0 on down and flat days. On an up day it is negative (short), and it grows with the size of the rise in usual daily moves, up to -20. The falling agitated profile is added by code, so the book is flat outside it.

Criterion:
- Horizon: 1 bar
- Main measure: Over the cases (bars with a non-zero forecast), the mean unusual move over the next 1 bar in the short direction. This is the negated next-day return minus the coin's mean daily return over all windows. Its t is computed with the cases of one day taken together.
- Supporting check: Across the cases, the least-squares slope of the short-direction unusual move on the size of the forecast (abs(forecast)) is above 0.
- Confirm: The main measure is above 0 with t >= 2, and the slope is above 0.
- Reject: The main measure is below 0 with t <= -2 (up days are followed by higher than usual returns).
- Inconclusive: A t between -2 and 2, or a main measure that confirms while the slope is at or below 0. At least 100 cases on at least 50 distinct days are needed, else the test is inconclusive.
