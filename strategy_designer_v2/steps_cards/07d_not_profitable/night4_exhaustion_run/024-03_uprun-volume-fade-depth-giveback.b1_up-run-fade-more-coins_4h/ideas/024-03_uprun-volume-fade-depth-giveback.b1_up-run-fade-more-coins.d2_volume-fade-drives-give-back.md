Idea: After an unbroken streak of rising four-hour periods, while the coin's 30-day return lies between a moderate fall and a slight rise, the coin falls over the next three days, the more so the more the volume declined from the streak's first four-hour period to its last, whatever the streak's gain relative to the coin's typical four-hour move.
Consequence: Let the volume fade, not the size of the run, set how large the short is, and use it only in flat to mildly falling months.
Why:
- F3: Across all 12,145 cases the unusual move is only +0.11 % per case over 18 bars (t 1.26, strength 0.012), which is half the 0.22 % cost of a trade. The total move is -0.41 % per case.
- F5: In the half of cases with the lower 30-day return, the volume fade grades the give-back. The unusual move rises from +0.28 % (t 1.09) in the least-faded quartile to +1.30 % (t 5.71, 1,136 cases) in the most-faded quartile. That top figure is about six times the cost of a trade.
- F6: The forecast's own grading does not hold.
