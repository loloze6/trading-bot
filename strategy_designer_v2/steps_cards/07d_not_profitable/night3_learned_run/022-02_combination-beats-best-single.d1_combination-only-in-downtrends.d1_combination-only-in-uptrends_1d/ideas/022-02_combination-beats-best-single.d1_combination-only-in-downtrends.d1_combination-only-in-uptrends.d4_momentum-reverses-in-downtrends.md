Idea: While a coin's 90-day return is not positive, the higher its 28-day return, the lower its return over the next 5 days.
Consequence: Outside a 90-day rise, a strong 28-day bounce is a reason to expect a fall, not to join it.
Why:
- F8: Outside a 90-day rise, the relation reverses. The 28-day return (−0.065, p 0.025) and closeness to the 90-day high (−0.074, p 0.007) both point to lower next 5-day returns.
