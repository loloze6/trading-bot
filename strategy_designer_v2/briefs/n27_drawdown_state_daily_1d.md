# The drawdown state on daily bars (night brief 27)
Where price sits against its own recent high is a slow state everyone watches. This brief asks whether that state, computed from the bars (distance from the 60 to 365 day high, days since the high), decides which daily rule pays: momentum near the high, reversal far from it, or a position size. Ideas must say the state and the rule. Fees 0.15% per round trip. All three coins must pass.
