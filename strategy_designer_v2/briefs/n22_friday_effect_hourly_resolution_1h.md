# The Friday effect at hourly resolution (night brief 22)
A daily effect is a sum of hours. This brief asks which hours of which weekdays carry the return on three coins, whether the effect is a drift or a few hours, and whether an hourly rule that holds only those hours pays after 0.15% per round trip. Ideas must name the UTC hours and days exactly. All three coins must pass.
